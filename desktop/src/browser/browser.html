Chrome / Safari 剪藏扩展导出的 .inkclip 文件，可用上方“导入剪藏文件”保存。

登录跳转诊断

仅在你点“开始”后，采集当前标签及其新弹窗，最多120秒、保留最近256条元数据；较早记录可能被覆盖。不会自动刷新、输入账号、提交表单或改变权限。

只记录主机、请求方法、资源类型、状态码、固定错误类别和表单结构计数。不记录完整网址、查询参数、请求正文、Cookie、输入值或页面内容；只有你点“保存”才写入本机JSON。

以上为可读简报；完整脱敏事件仍可明确导出到你选择的本机JSON。API显示“未测得”表示脚本未成功，不表示不支持。
