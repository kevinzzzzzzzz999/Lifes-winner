阅读、搜索、保存灵感

在地址栏输入网址或关键词。选中文字后点击“剪藏”，可保存到当前资料夹或打开浏览器时选中的白板。

网页图片可右键剪藏可见区域；相机、麦克风和定位权限暂不开放。

关闭窗口后会恢复上次的网址和标签顺序；表单、运行状态和网页后退记录不会恢复。

Chrome / Safari 剪藏扩展导出的 .inkclip 文件，可用上方“导入剪藏文件”保存。

浏览器扩展

加载你信任的解压扩展文件夹。安装前会列出它声明的网页访问权限。

仅兼容 Electron 支持的部分 Chrome 扩展 API。无法直接安装商店 .crx；Safari 扩展不能在这里加载。含工具栏弹窗或后台服务的扩展可能只有部分功能可用。
