# AI 网页助手（65e）

在设置中选择 ChatGPT、DeepSeek、Claude 或 Gemini，应用只记住上次的服务。用户在普通网页中自行登录；不添加后台认证或 API 密钥要求。API 高级页沿用独立设置。

每个服务保留自己的 WKWebView，关闭或切换面板后回到同一实例。默认网站数据仓库保留网站 Cookies；登录是否仍有效由网站决定。

框选截图只生成内存预览，不写源文档。点击“复制截图”后可自行长按粘贴。“放入 AI 输入框”也必须明确点击：先复制 PNG，再校验选中服务的精确 HTTPS origin、聊天路径和明确的输入框标识，尝试公开系统 paste: 动作。界面要求用户确认图片附件，最后由用户发送；程序不会提交消息。服务、网页、剪贴板或截图变化时取消异步粘贴。无法可靠找到输入框或系统不允许粘贴时，明确提示手动粘贴，不声称已上传。

程序不读取聊天记录、账户内容或草稿文字。只检查可见的输入框标识并聚焦。系统浏览器入口始终对应所选服务。复制图片仅写本机剪贴板，十分钟过期。

独立验证：`python3 Tests/AIWeb65/run-host.py --device <专用已启动模拟器 UUID> --work <独立输出目录>`。最终合成 WK 测试 53 项通过，包括实际 PNG paste 事件、无 submit、草稿保留、切服务取消、错误接收方拒绝和手工 fallback。它不代表四家真实网站的登录或上传已验证。完整证据及源文件哈希位于 `../../evidence/native-ai65e/`。
